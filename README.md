# PartePracticaBD

Se desarrollo un sistema de generación de turnos para la empresa LiMar, este sistema busca organizar y administrar la asignación de servicios a diferentes tipos de usuarios.

El entorno de trabajo fue implementado mediante la creación de dos contenedores: uno para el motor de base de datos PostgreSQL 14, y otro para la herramienta de administración pgAdmin 4. A través de estos servicios se logró la configuración y conexión entre ambos, así como la creación de la base de datos servilimar, donde se almacenan las entidades necesarias para el sistema de turnos.
